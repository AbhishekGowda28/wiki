# Compound Engineering

This is more of a agentic skill organization of solving code problems that follows certain path.

## How I am using this

If I have an idea I start out with ce:ideation phase, then move along. But if there is already a good grommed idea or a ticket, I can start from ce:plan phase to create document.
Once the planned document is created, I can work on it.

If the ticket is not groomed, then I'll start from ce:brainstrome phase.

One other thing what I am doing is using different modals between different phases. There are 2 phases by default plan & build.
