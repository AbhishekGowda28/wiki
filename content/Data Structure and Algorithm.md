# Data Structure and Algorithm

## Introduction

**Algorithm** is a sequence of steps followed to transform input into output. We can provide same set of input, if the sequence of steps are different we get different outputs.
Example, consider any 2 number, if they are added we get sum of the 2 number, when the same numbers are substracted, we get difference between 2 numbers.
Algorithm defines the relationship between inputs\&outputs.
We can say the algorithm is correct, when algorithm halts with same output for same instance of inputs.

**Data Structure** is a way to store data in order to access and modify.

- Q) Why do we need Algorithms and Data structure?
- NP-Complete problems: These are problems where there are no solution

Data Structure and algorithms are important even if we have faster computers.
