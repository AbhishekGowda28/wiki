# Hands on machine learning

> Machine learning is a field of computer sciences, where the machines are used to answer new problems that are not previously known to the users.

Types of machine learning systems

- Training supervision
  - Supervised learning
  - Un supervised learning
  - semi supervised learning
  - self supervised learning
  - reenforcement learning
- Batch vs online learning
- Instance vs modal based learning

Different types of data

- Training data
- Training-Development data
- Dev data
- Test data

There are also challenges with machine learning. The challenges arise from 2 things.

1. Data
2. Algorithm / modal
   When the incorrect data is used, the modals will start giving wrong/incorrect results

> Garbage in, Garbage out

The validation and testing of the features the modal is trained on should be right, if not the modal again will output incorrect results.
