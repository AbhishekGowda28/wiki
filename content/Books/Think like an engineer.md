# Think like an engineer

> [!book-theme]

In the starting preface, author took a long route of explaining how the current problem had a solution (serious of solutions) that helped in solving the problem.

> [!quote] Engineering is not only about [[Systems Thinking]] but also about systems building

Systems thinking - where engineer needs to understand the modular actions of each pieces and how these pieces contribute to the whole systems.
System building - its not only enough to understand the system and its modules, engineer by nature are builders, they should have intrinsic understanding of building things. Only when an engineer understands the system he can build better systems.

Book talks about 3 things that is important in engineering

1. Structure
2. Constraints
3. Trade off
